# 실거래가 분석 · 웹 버전

기존 Windows v1.13의 아파트·오피스텔 **매매** 분석을 브라우저에서 사용할 수 있게 옮겼습니다. 전월세 분석은 지원하지 않습니다.

## 바로 사용하기

- **offline.html**을 Chrome 또는 Edge로 열면 설치 없이 사용할 수 있습니다. 원본 엑셀을 선택하거나 페이지로 끌어 놓으세요.
- 웹에 배포한 뒤에는 배포 주소에 접속해서 같은 방식으로 사용합니다.
- 브라우저 안에서 파일을 분석하며 파일·거래 데이터를 서버로 전송하거나 브라우저 저장소에 저장하지 않습니다. 새로고침하면 결과가 사라집니다.
- 국토부 다운로드 링크를 클릭할 때는 인터넷이 필요합니다.
- 보안 정책으로 자동 복사가 막히면 텍스트 복사 창이 표시됩니다. 표 복사는 최신 Chrome/Edge의 HTTPS 웹 주소에서 사용하는 것을 권장합니다.

## 지원 기능

- 아파트·오피스텔 매매 원본 .xlsx 자동 인식. 한 번에 한 파일이며 새 파일은 이전 결과를 대체합니다.
- 단지·주소·타입별 평균/최소/최대 평당가와 거래금액, 거래 건수.
- 동·단지별 평균과 제외 내역.
- 동·단지·타입·건축년도 다중 필터. 타입은 10단위 묶음 선택 가능.
- 시작일·종료일을 포함하는 계약기간 필터. 기간 초기화는 다른 필터를 유지합니다.
- 개별 사례 분석: 단지 및 타입 선택, 월별/일별 평균 그래프, 점을 가리키거나 키보드로 선택하면 가격과 거래 건수 표시, 개별 거래 표.
- 숫자 기준 정렬, 열 제목 드래그 순서 변경, 행 체크 선택, 표 복사, 셀 더블클릭 텍스트 복사.
- 기본은 열 제목 없이 복사. 평당가는 반올림한 정수 숫자로 복사합니다.
- 현재 화면의 필터·검색 결과에 대한 전체 복사. 페이지 구분 없이 모든 결과를 표시하고 복사하며 숨겨진 필터 밖 행은 포함하지 않습니다.
- 필터·검색과 관계없는 전체 결과를 원본/단지별/동·단지별 3개 시트로 저장. 소수 정밀도는 저장 파일에 유지합니다.
- 출처·조회기간·조회범위·산식 복사.

## 계산 기준

개별 평당가 = 거래금액(만원) ÷ 실제 전용면적(㎡) × 3.305785

평균은 개별 거래 평당가의 산술평균입니다. 면적은 소수점을 버려 59.01~59.99㎡를 59타입으로 묶습니다. 평형은 전용면적을 평으로 환산한 값이며 공급평형이 아닙니다.

직거래·해제 거래·소재지 미확인·다른 시군구 중개사·입력값/거래유형 확인 필요 거래를 제외합니다. 중개사가 여러 곳이면 모두 같은 시군구여야 포함합니다. 개인 매수·매도자의 중개거래는 포함합니다.

‘행정동’은 원본 주소의 법정동·읍·면입니다. 이름이 같은 단지는 주소로 구분합니다. 검색은 표시 행만 제한하고 평균을 다시 계산하지 않으며, 개별 사례 분석에는 검색어가 적용되지 않습니다. 그 외 필터와 계약기간은 평균과 그래프를 다시 집계할 때 반영됩니다.

월별/일별 그래프는 같은 전용 타입으로 비교하는 것이 좋습니다. 전체 타입을 섞으면 면적 구성 변화가 평균에 영향을 줄 수 있습니다. 거래 없는 기간은 0원으로 처리하지 않고 생략합니다. 선은 점 사이를 연결한 참고 표시입니다. 날짜 미확인 거래는 개별 표에는 남고 그래프에는 포함되지 않습니다.

## GitHub Pages에 배포하기

원본 엑셀이나 EXE는 올리지 마세요. 이 폴더에는 실제 거래 데이터가 포함되지 않습니다.

1. GitHub에서 새 저장소를 만듭니다. 무료 계정의 일반적인 Pages 사용은 공개 저장소 기준입니다. 소스 공개 범위를 확인하세요.
2. 이 프로젝트의 **내용 전체**를 저장소의 `main` 브랜치에 올립니다. 숨김 폴더 `.github`도 포함해야 합니다.
3. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
4. **Actions → Deploy real estate analyzer → Run workflow**를 실행합니다. 이후에는 main에 수정 파일을 올리면 다시 배포됩니다.
5. 완료 후 Settings → Pages에 표시되는 웹 주소를 공유합니다.

Git 명령으로 올릴 경우 이 폴더에서 다음을 실행합니다. 저장소 주소는 본인의 새 저장소 주소로 바꿉니다.

```sh
git init -b main
git add .
git commit -m "Create browser-based real estate analyzer"
git remote add origin https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY.git
git push -u origin main
```

GitHub Pages 워크플로는 `dist` 폴더만 공개 웹사이트로 배포합니다. 프로젝트 저장소의 이름이 바뀌어도 상대 경로로 작동합니다. 외부 CDN, 서버 API, DB, 로그인은 사용하지 않습니다. 사용자의 원본 파일은 Git에 올리지 않아야 합니다. `.gitignore`에 엑셀 등 데이터 확장자를 제외해 두었습니다.

[GitHub Pages 공식 워크플로 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## 로컬 개발

Node.js가 있으면 별도의 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. `dist/index.html`은 모듈을 사용하므로 파일을 직접 더블클릭하는 대신 서버로 열어야 합니다. 더블클릭용은 별도로 제공한 `offline.html`입니다.

```sh
node tests/engine.test.mjs
node build-offline.mjs
```

`dist` 파일을 수정한 후 마지막 명령을 실행하면 offline.html도 갱신됩니다.

## 구성과 개인정보

- `dist/engine.js`: 집계·필터·추이 계산. 네트워크 접근 없음.
- `dist/xlsx.js`: 브라우저 내 XML/ZIP 읽기 및 Excel 저장. 원본의 잘못된 워크시트 크기 정보에 의존하지 않음.
- `dist/app.js`, `style.css`: 화면·표·그래프·클립보드.
- `dist/vendor/jszip.min.js`: JSZip 3.10.1, MIT 라이선스 동봉. 외부에서 실행 중 다운로드하지 않음.
- CSP `connect-src 'none'`으로 페이지의 데이터 전송 연결을 차단합니다. 업로드 파일을 저장하는 서버 코드는 없습니다.
- 지원 브라우저에서는 읽기 전용 WebMCP 분석 건수 요약 도구를 등록합니다. 이는 파일을 전송하지 않습니다.

대용량 보호 한도는 압축 파일 200MB, 개별 내부 파일 300MB, 전체 압축 해제 700MB, 거래 25만 건입니다. 기기의 메모리나 회사 보안 정책에 따라 실제 사용 가능 크기는 더 작을 수 있습니다. Excel 날짜가 별도 날짜형으로 변환된 재가공 자료보다 국토부 원본 파일 사용을 권장합니다.
