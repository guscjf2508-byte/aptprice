# v2.8 종합 리포트 · 선택 단지 세대수 조회

## 이번 변경
- 종합 리포트 탭을 개별 사례 분석과 제외 내역 사이에 배치했습니다.
- 결론을 맨 위에 배치하고 목차를 구성했습니다. 목차를 누르면 해당 항목으로 이동합니다.
- 단지별·타입별 사례 분석은 제목을 눌러 접고 펼칩니다. 기본값은 접힘입니다.
- 리포트는 업로드 자료와 현재 지역·타입·건축년도·계약기간·신규/갱신·거래 포함·수동 제외 조건을 반영합니다. 검색은 단지명·주소 기준입니다.
- 기준연도는 raw data 조회 종료연도, 건축년도 차이 10년 이내, 59·84타입을 기본값으로 합니다. 건축년도 차이이므로 정확한 준공일 기준 10년과 다릅니다.
- 거래 1건도 표시하며, 거래건수는 집계표의 맨 오른쪽입니다.
- 월별·분기별 평균 거래가격/평당가 및 전기 대비를 표시합니다. 전기에 거래가 없거나 비교 기간이 부분 기간이면 증감률을 계산하지 않습니다.
- 전월세는 실제 전세금·보증금·월세를 먼저 보여주고 환산 월세는 뒤에 배치합니다. 월세 실제 계약조건도 표시합니다.
- 리포트 결론은 클릭해서 수정할 수 있습니다. 리포트 복사와 인쇄/PDF를 지원합니다.

## 세대수 조회
기본 분석표에는 세대수 열이 없습니다. 전국 자료를 미리 다운로드하거나 자동 수집하지 않습니다.

1. 아파트 자료를 열고 단지별 평당가 분석(전월세는 단지별 임대료 분석)에서 단지명을 누릅니다.
2. 펼친 거래 사례 영역의 세대수 조회를 누릅니다.
3. 처음 한 번 API 인증키를 입력하고 세대수 조회를 다시 누릅니다. 인증키는 현재 창에서만 사용하며 파일·브라우저 저장소에 저장하지 않습니다. 새로고침 후에는 다시 입력합니다.
4. 국토교통부 API에서 단지 목록과 기본정보를 조회합니다. 주소와 단지명으로 확인한 한 단지만 세대수를 표시합니다.
5. 조회한 세대수는 종합 리포트를 다시 작성하면 반영됩니다. 세대수는 단지 전체 값이며 59·84타입별 세대수가 아닙니다.

인터넷이 필요합니다. 원본 엑셀은 전송하지 않으며 API에는 인증키·시도코드·단지코드만 전달합니다. 미등록·주소 비공개·후보 복수·세대수 0/미제공·기관 오류는 임의로 채우지 않고 안내합니다. API 오류가 나도 가격 분석 결과는 유지합니다.

## GitHub 배포 업데이트
ZIP을 풀어 dist, scripts, tests 폴더와 build-offline.mjs, offline.html, package.json, server.mjs, README.md를 저장소 최상위의 같은 경로에 덮어 올리세요. ZIP 자체나 바깥 폴더를 올리지 않습니다.

기존 .github/workflows/pages.yml은 유지하면 됩니다. 세대수용 GitHub Secret은 필요 없습니다. 전환율용 REB_API_KEY 설정은 기존대로 유지합니다. Actions 성공 뒤 사이트를 새로고침하세요. 공개 배포 파일에 API 인증키를 넣지 마세요.

## 지원 범위
기존 아파트·오피스텔 매매/전월세 및 연립다세대·분양입주권·단독다가구·상업업무용·공장창고등 매매 분석을 유지합니다. 종합 리포트와 세대수 조회는 아파트 대상입니다. 서로 다른 유형·거래종류의 파일은 통합하지 않습니다.

자동 검증에는 가격 집계, 중복 정리, 수동 제외, 건축년도/타입 선정, 전기 대비, 후보 주소 확인, API 오류/미제공 및 단일 HTML 구문 검증이 포함됩니다. 실제 아파트 원본 업로드, 리포트 탭·목차·접기/펼치기와 용산데시앙포레 384세대 실제 API 조회를 확인했습니다. GitHub 공개 사이트에는 직접 배포하지 않았습니다.
